Azure Stack

How this app is built
Container Apps Hosts the FastAPI API + this frontend in one container — no Kubernetes needed
Azure Maps Renders map tiles, GeoJSON layers, popups, and the 1.5 km access buffer
Blob Storage Stores raw and processed GeoJSON from RCRC — the app reads it at startup
Cosmos DB Stores route summaries, district scores, and simulated live delay events
App Insights Tracks request latency, errors, and health across the deployed app
azd up deploys all five services into one Azure resource group
